## 2. 测试目的

验证平台一期核心功能是否满足需求分析说明书中的功能和非功能要求，重点包括：

- 文档管理、AI转Markdown、文档概览和删除清理。
- 知识库导入、向量化和语义检索。
- ToC随行专网和ToB物联网专网数据查询。
- 受限只读查询和查询范围安全控制。
- 辅助问答的业务分流、来源标注和严格空结果约束。

## 3. 测试范围

### 3.1 在测范围

- 文档分类管理
- 文档上传与元数据管理
- 文件预览
- AI转Markdown
- Markdown编辑与预览
- 文档编辑和删除
- 文档概览统计
- 知识库导入和向量化
- 知识检索与来源展示
- ToC随行专网查询
- ToB物联网专网查询
- 受限只读查询工具
- 辅助问答
- 多轮上下文与来源标注
- 安全与异常场景

### 3.2 不在本期验收范围

- 完整智能体自主规划。
- 自主告警、巡检、自动化处置和工单联动。
- Rerank精排和混合检索优化。
- 移动端原生应用。

## 10. 缺陷汇总

本期测试未发现未关闭的阻断性缺陷。

曾出现并已处理的典型问题包括：

1. 大文档资源清单过长导致数据库字段截断，已调整为可承载完整清单的字段类型。
2. 转换失败备注过长导致状态更新失败，已调整备注字段类型。
3. 转换状态存在“成功”等旧状态，页面已统一展示为“转MD成功”。
4. 历史失败备注在后续成功转换后未清理，已增加成功保存后清理逻辑。
5. 知识库命中附件文件但正文片段未进入上下文，已调整召回数量和提示词约束。

## 11. 测试结论

平台一期核心功能满足结项文档范围要求：

1. 文档管理、AI转Markdown、预览、编辑、删除和概览统计功能可用。
2. 知识库导入、向量化和语义检索功能可用，并能展示引用。
3. ToC随行专网和ToB物联网专网数据查询功能可用。
4. 受限只读查询具备表白名单、危险SQL拦截和分页限制。
5. AI辅助问答具备业务分流、数据库来源标注、严格空结果和禁止推测约束。
6. 一期定位为辅助问答能力，不将本项目作为完善智能体验收，符合二期规划边界。

建议：正式验收前由项目组按实际验收环境执行一轮回归，并由测试负责人补充签名和测试日期。
