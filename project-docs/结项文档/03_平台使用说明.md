# 平台使用说明

## 1. 文档信息

| 项目 | 内容 |
| --- | --- |
| 项目名称 | 5G专网运营支撑系统（一期） |
| 文档版本 | V1.0 |
| 编制日期 | 2026年8月24日 |
| 适用对象 | 业务管理员、文档管理员、运维人员、系统管理员 |

## 2. 平台入口

1. 打开浏览器访问平台地址。
2. 输入用户名和密码登录。
3. 登录后进入平台首页。

首页提供以下入口：

- 文档管理
- 文档管理概览
- AI知识库
- 随行专网查询
- AI对话

## 3. 角色与权限

| 角色 | 建议权限 |
| --- | --- |
| 系统管理员 | 用户、角色、菜单和系统配置管理 |
| 业务管理员 | 分类管理、文档上传、文档概览、知识库、数据查询、AI问答 |
| 普通业务用户 | 文档查看、知识库查看、数据查询、AI问答 |

菜单不可见时，请由系统管理员在角色授权中勾选对应菜单，保存后重新登录。

## 4. 文档分类管理

### 4.1 进入

进入“文档管理模块”下的“分类管理”页面。

### 4.2 新增分类

1. 选择父级分类。
2. 填写分类编码和分类名称。
3. 保存。

分类支持三级结构：

```text
一级分类
├── 二级分类
│   └── 三级分类
```

分类编码用于树形关系和存储目录预览，展示名称用于页面显示。

### 4.3 停用分类

已停用分类不再参与新建文档选择。历史文档仍保留原有分类路径。

## 5. 文档上传

### 5.1 操作步骤

1. 进入“文档管理”页面。
2. 选择三级分类。
3. 填写显示名称、文件年份和备注（可选）。
4. 选择文件。
5. 点击“上传”。

### 5.2 支持类型

支持以下常见类型：

- PDF
- Word（doc/docx）
- PowerPoint（ppt/pptx）
- Excel（xls/xlsx）
- CSV
- 图片
- 文本
- Markdown
- ZIP Markdown资源包

### 5.3 上传后状态

上传成功后，文档记录初始状态为“已上传”。此时可以继续执行AI转MD、预览或编辑。

## 6. 文件预览

在文档管理列表中找到目标文档，点击“预览”。

预览规则：

| 文件类型 | 预览方式 |
| --- | --- |
| PDF | 在线PDF预览 |
| Office文档 | 转换为PDF后预览，转换失败可下载原文件 |
| 图片 | 图片预览 |
| CSV | Markdown表格或文本预览 |
| 文本 | 文本预览 |
| Markdown | Markdown预览 |
| Markdown资源包 | Markdown预览及图片展示 |

预览弹窗提供：

- 全屏
- 退出全屏
- 下载原件

## 7. AI转Markdown

### 7.1 操作

1. 在文档管理列表选择文档。
2. 点击“更多”。
3. 点击“AI转MD”。

### 7.2 状态说明

| 页面状态 | 含义 |
| --- | --- |
| 排队中 | 任务已提交，等待解析服务处理 |
| 解析中 | 正在生成Markdown和图片资源 |
| 转MD成功 | Markdown已生成，可查看结果或导入知识库 |
| 转MD失败 | 转换未完成，可查看备注后重新提交 |

处理中状态会显示排队数和已耗时，页面会自动刷新。

### 7.3 查看Markdown结果

文档转MD成功后，在“更多”菜单中点击“MD结果”，可查看Markdown内容和图片。

## 8. Markdown编辑

### 8.1 操作

打开Markdown预览后，可进入编辑模式，修改Markdown正文并保存。

### 8.2 注意事项

- 修改保存后，如需用于知识库问答，应重新导入或重建知识库文档。
- 图片资源仍需通过平台资源代理访问。

## 9. 文档编辑

在文档管理列表点击“编辑”，可修改：

- 显示名称
- 年份
- 备注
- 状态
- 是否最新

保存后文档列表和概览统计同步更新。

## 10. 文档删除

1. 在文档管理列表点击“更多”。
2. 点击“删除”。
3. 确认删除。

删除后系统会同步清理对象存储中的源文件、Markdown和图片资源。清理失败时系统保留清理标记并在服务启动后自动重试。

## 11. 文档管理概览

### 11.1 功能

概览页用于查看整体文档情况：

- 文档记录数
- 最新版本数
- 转换处理中
- 转MD成功
- 转MD失败
- 可用MD
- 源文件总大小
- 状态分布
- 文件类型分布
- 分类分布

### 11.2 统计口径

- 统计范围包含全部上传记录和历史版本。
- 最新版本以“最新”标记为准。
- 源文件总大小按原始上传文件统计，不包含Markdown、图片和中间产物。

## 12. AI知识库

### 12.1 新建知识库

1. 进入“AI知识库”页面。
2. 新建知识库。
3. 配置知识库名称和向量模型。
4. 保存。

### 12.2 从文档导入知识库

1. 在文档管理列表选择已转MD成功的文档。
2. 点击“更多”。
3. 点击“导入知识库”。
4. 选择目标知识库。
5. 点击“导入”。

### 12.3 知识库向量化

知识库文档导入后，需要执行向量化/重建，才能参与语义检索。

### 12.4 检索使用

知识库检索结果会展示文档标题、内容片段和来源引用。命中内容中的Markdown图片由平台资源代理提供访问。

## 13. 随行专网查询

### 13.1 入口

进入“随行专网查询”页面。

### 13.2 页面结构

页面包含四个页签：

- 项目总览
- 网络资源
- 地址池与路由
- 文档检索

顶部展示汇总指标：

- 随行专网项目
- 已开通项目
- 预计终端用户
- 网络资源项

### 13.3 项目总览

查询项目名称、客户、DNN/APN、ServiceID、带宽、UPF、预计用户数、资源数量和状态。

点击“编辑”可修改：

- 项目状态
- 要求开通日期
- 带宽
- 预计用户数
- DNN/APN
- UPF
- 备注

### 13.4 网络资源

支持按项目筛选，也可输入IP、资源名称、资源类型等关键词搜索。

### 13.5 地址池与路由

查询每个项目在不同UPF下的终端地址池、客户内网网段、静态路由、下一跳和VPN/VRF。

### 13.6 文档检索

查询申请表、网管反馈、GRE参数和资源反馈中的文本内容。

注意：切换页签时会清除当前关键词，但保留项目筛选。

## 14. AI辅助问答

### 14.1 入口

从首页进入“AI对话”，或使用平台提供的问答地址。

### 14.2 使用方式

直接输入问题，例如：

- 5G专网项目纳管有什么要求？
- 山西大学随行专网的DNN是什么？
- 某项目固定IP对应的CPE和SIM卡信息是什么？
- MEC部署有哪些注意事项？

### 14.3 回答范围

问答支持以下场景：

1. 与5G专网、ToB物联网专网或ToC随行专网无关的问题。
2. ToB物联网专网现场项目问题。
3. ToB物联网专网非现场知识问题。
4. ToC随行专网现场项目问题。
5. ToC随行专网非现场知识问题。
6. 业务方向不明确的问题。

### 14.4 数据库来源

当回答来自ToB或ToC数据库查询时，回答开头会显示：

```text
数据来源：AI5G专网查询插件（ToB数据库/ToC数据库）
```

前端也会在回答下方展示对应的数据库来源标签。

### 14.5 未命中提示

平台采用严格回答策略：

- 数据库未命中时回复“未找到相关记录”，并请用户补充项目名称、项目编码、固定IP、ICCID、MSISDN、车辆/设备编号、DNN、ServiceID、UPF等。
- 知识库未命中时回复“知识库中暂未找到相关记录”。
- 禁止模型编造、推测或隐瞒空结果。

### 14.6 多轮补充

当第一轮问题缺少关键信息时，系统会要求补充条件。补充后再问一次，可基于历史上下文继续查询。

示例：

```text
用户：查询CPE和SIM卡信息
AI：我暂时无法判断具体项目，请补充项目名称、固定IP或ICCID。
用户：交通银行，固定IP是10.10.10.10
AI：数据来源：AI5G专网查询插件（ToB数据库）...
```

## 15. 常见问题

### 15.1 菜单看不到

确认当前账号已授权对应角色，并由管理员勾选“文档管理模块”相关菜单。保存后重新登录。

### 15.2 上传后没有立即转MD

上传完成后，需要在文档管理列表手动点击“AI转MD”。

### 15.3 转MD一直处理中

处理中状态会显示排队数和已耗时。若长时间无变化，可查看后端日志或重新提交。

### 15.4 转MD失败

查看文档备注中的错误信息，确认源文件可读取后重新提交。

### 15.5 知识库搜不到新资料

确认已导入知识库，且知识库文档已完成向量化。文档更新后需要重新导入或重建。

### 15.6 文档预览图片不显示

确认Markdown中的图片使用平台资源代理地址，且对应文档资源包未删除。

### 15.7 删除文档后空间未减少

删除任务可能处于失败重试状态。联系管理员检查清理记录和后端日志。

### 15.8 AI回答没有查数据库

只有ToB或ToC现场项目问题才先查数据库。通用知识问题使用知识库回答，不以数据库作为必查路径。

### 15.9 AI回答出现未找到

请补充项目名称、项目编码、固定IP、ICCID、MSISDN、车辆/设备编号、DNN、ServiceID、UPF等条件后重试。

## 16. 运维建议

### 16.1 定期检查

- 查看文档管理概览中的处理中和失败数量。
- 检查对象存储中是否存在未清理资源。
- 检查知识库文档是否已完成向量化。

### 16.2 数据维护

- 原始资料变更后，同步更新平台文档并重新导入知识库。
- ToC或ToB数据重新导入前，确认手工修改是否已同步回原始资料。
- 建立新增项目资料的标准化目录和命名规范。

### 16.3 AI问答维护

- 新增知识库文档后及时向量化。
- 数据库数据更新后无需重新训练，可直接查询。
- 如发现回答不准确，优先检查知识库召回和查询规则。
