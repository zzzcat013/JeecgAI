# 助手辅助类文档目录

本目录用于集中存放我为本项目生成的“辅助类/工具”文档，覆盖后端 `jeecg-boot`（Java）与前端 `jeecgboot-vue3`（Vue3）。

## 目录结构
- backend/：后端（Java，Spring Boot）辅助类文档
- frontend/：前端（Vue3/Vite/TS）辅助类文档

## 命名与内容约定
- 后端文档命名：`<模块>/<类名>.md`
  - 内容包含：用途简介、关键方法/接口、依赖与配置、示例用法、注意事项
- 前端文档命名：`<模块>/<组件或工具名>.md`
  - 内容包含：用途简介、API/属性、依赖与配置、示例用法、注意事项

## 更新策略
- 每次新增或调整辅助类/工具时，同步在本目录下新增或更新对应文档。
- 文档以中文为主，必要时补充英文术语以便检索。

## 对应模块说明（参考）
- 后端根路径：`jeecg-boot/`
- 前端根路径：`jeecgboot-vue3/`

如需将现有类的说明补全，请在相应子目录下新增文件并按约定编写。
